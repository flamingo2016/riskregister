# Risk Register Repository

This repository contains the initial risk register for the Teradata to Google Cloud Platform (GCP) migration project.

## Purpose

- Store the planning-phase risk register as a standalone deliverable
- Provide a central document for early-stage stakeholder alignment
- Support refinement into the final PID risk register

## Contents

- `Risk_Register_Teradata_to_GCP.docx` — the Word document with a complete risk register covering technical, regulatory, resourcing, vendor, change-management, operational, data quality, security, and timeline risks.

## Project Context

- Domain: Telecom (Dallas, TX)
- Migration: Teradata enterprise data warehouse to BigQuery on GCP
- Estimated budget: $3.5M
- Focus: planning-phase risk identification and mitigation

## Notes

This repository intentionally contains only the risk register document for the project.
